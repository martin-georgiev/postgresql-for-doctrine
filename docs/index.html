Use PostgreSQL's own types and functions in Doctrine

Map arrays, JSONB, ranges, PostGIS geometries, pgvector embeddings and over 100 column types to your entities, and call over 450 PostgreSQL functions and operators straight from DQL.

composer require martin-georgiev/postgresql-for-doctrine

Set it up with Doctrine, Symfony or Laravel.

The query you would write in PostgreSQL, and the DQL that produces it.

PostgreSQL
SELECT id FROM users
WHERE profile ->> 'country' = 'NL'

DQL
SELECT u.id FROM App\Entity\User u
WHERE JSON_GET_FIELD_AS_TEXT(u.profile, 'country') = 'NL'

WHERE to_tsvector('english', body)
  @@ plainto_tsquery('english', :terms)

DQL
SELECT a.id FROM App\Entity\Article a
WHERE TSMATCH(
  TO_TSVECTOR('english', a.body),
  PLAINTO_TSQUERY('english', :terms)
) = TRUE

  SUM(amount) OVER (PARTITION BY customer_id ORDER BY placed_at)

DQL

  OVER(SUM(o.amount), PARTITION BY o.customer ORDER BY o.placedAt)

PostgreSQL
SELECT customer_id,
  COUNT(*) FILTER (WHERE status = 'paid') AS paid,
  PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY total) AS median
FROM orders GROUP BY customer_id

DQL
SELECT IDENTITY(o.customer),
  FILTER(COUNT(o.id), WHERE o.status = 'paid') AS paid,
  PERCENTILE_CONT(0.5 WITHIN GROUP ORDER BY o.total) AS median
FROM App\Entity\Order o GROUP BY o.customer

From install to your first query

  1. Install the package

    composer require martin-georgiev/postgresql-for-doctrine

  2. Register what you use

    Register each type and function with Doctrine, or list them in your Symfony or Laravel configuration.

    use Doctrine\DBAL\Types\Type;
use MartinGeorgiev\Doctrine\DBAL\Types\TextArray;
use MartinGeorgiev\Doctrine\ORM\Query\AST\Functions\Contains;

Type::addType('text[]', TextArray::class);
$configuration->addCustomStringFunction('CONTAINS', Contains::class);

  3. Map the column and query it

    #[ORM\Column(type: 'text[]')]
private array $tags;

$em->createQuery('
    SELECT p FROM App\Entity\Post p
    WHERE CONTAINS(p.tags, ARRAY(:tag)) = TRUE
')->setParameter('tag', 'postgres')->getResult();
